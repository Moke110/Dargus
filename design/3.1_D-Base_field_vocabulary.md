# D-Base Field Vocabulary

> D-Base records share one schema so researchers and consumers of the store use the same language. Three additional fields — the lifecycle `status` (with `superseded_by`), the LLM summary, and the embedding — live outside records in sidecar tables keyed by `evidence_id` (embeddings also by model fingerprint).

## Field groups

| Group | Keys | Purpose |
|---|---|---|
| Identity | `evidence_id`, `biological_level`, `is_clinical`, `evidence_design`, `sources`, `source_entry`, `source_time` | Identify the record and its primary provenance |
| xy shape | `xy.count` | Descriptive / pairwise / sequential |
| x-axis | `x.type`, `x.unit`, `x.value` | Experimental variable |
| y-axis | `y.type`, `y.category`, `y.unit`, `y.to_basis`, `y.value`, `y.dispersion`, `y.n_total`, `y.events`, `y.p_value`, `y.direction`, `y.effect`, `y.assay` | Outcome, statistics, and assay platform |
| Background | `bg.disease_id`, `bg.drugs`, `bg.genes`, `bg.model`, `bg.dose_value`, `bg.dose_unit`, `bg.duration_value`, `bg.duration_unit`, `bg.phenotype` | Shared context, intervention parameters, and phenotypes |
| Sample | `cell_line_id`, `model_organism`, `strain`, `sex`, `age`, `tissue`, `cell_type`, `exvivo_platform` | Biological source and subject descriptors |
| Clinical | `clinical_design.comparator_type`, `clinical_design.blinding`, `clinical_design.randomized`, `clinical_design.phase`, `clinical_design.n_arms`, `clinical_design.population`, `clinical_design.study_id` | Trial structure for clinical records |
| Metadata | `related_evidence_id`, `is_primary_endpoint`, `p_value_adjusted` | Cross-record links and study context |

## Sidecar fields

| Field | Sidecar | Purpose |
|---|---|---|
| `status` | `sidecars/status.jsonl` | Lifecycle state (`active`, `superseded`, `retracted`, `holdout-test`, `holdout-valid`); latest entry per `evidence_id` wins |
| `superseded_by` | `sidecars/status.jsonl` | `evidence_id` of the replacing record, carried on `superseded` entries |
| LLM summary | `sidecars/llm_summary.jsonl` | Fallback free-text representation of the record |
| embedding | `sidecars/embeddings-{model_fp}.jsonl` | Dense vector for semantic search, per embedding-model fingerprint |

Sidecar fields never participate in the `evidence_id` identity hash.

## Key enumerations

- **Biological levels (11):** `molecular`, `molecular-sim`, `cellular`, `cellular-sim`, `exvivo`, `exvivo-sim`, `animal`, `animal-sim`, `rct`, `epi`, `rct-sim`
- **Evidence design (7):** `two_arm_comparison`, `single_arm`, `dose_escalation`, `dose_response_curve`, `observational_association`, `continuous_trajectory`, `descriptive`
- **x.type (5):** `drug`, `gene`, `concentration`, `time`, `combination`
- **y.category (23):** clinical efficacy/toxicity categories plus `binding`, `pk_adme`, `prot_exp`, `rna_exp`, `viability`, `apoptosis`, `proliferation`, `migration`, `invasion`, `autophagy`, `differentiation`, `phosphorylation`, `localization`, `metabolism`, `oxidative_stress`, `behavioral`, `other` — used for filtering and aggregate reporting
- **y.to_basis (5):** `absolute`, `change`, `fold_change`, `log2_fold_change`, `log10_fold_change`
- **y.direction (3):** `beneficial`, `harmful`, `neutral`
- **Status (5):** `active`, `superseded`, `retracted`, `holdout-test`, `holdout-valid` — sidecar field, not part of the record schema

## Cardinality

| Symbol | Meaning |
|---|---|
| R | Required |
| C | Conditionally required |
| O | Optional |
| D | Derived by D-Base |

## External identifiers

D-Base prefers stable external CURIEs: MONDO/DOID/OMIM for diseases, Cellosaurus for cell lines, UBERON for tissues, CL for cell types, NCBITaxon for organisms, HPO for phenotypes, and clinicaltrials.gov NCT numbers for trials.
