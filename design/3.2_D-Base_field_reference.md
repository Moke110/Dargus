# D-Base Field Reference

> Field-by-field semantics for the D-Base evidence schema. Three sidecar fields (status/superseded_by, LLM summary, embedding) live outside the record; see below.

## Legend

| Symbol | Meaning |
|---|---|
| R | Required |
| C | Conditionally required |
| O | Optional |
| D | Derived by D-Base |
| in_id | Whether the field participates in the `evidence_id` content hash |

---

## Identity

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `evidence_id` | `str` | D | N | Stable content-addressed identifier. `ev_` + first 16 characters of `sha256(identity_fields)`. Never assigned by callers. |
| `biological_level` | `enum` | R | Y | Biological level of the evidence. One of 11 values spanning molecular to clinical, including `-sim` variants. Determines conditional requirements. |
| `is_clinical` | `int` (0 or 1) | D | N | Derived flag. `1` for `rct` and `epi`, `0` for all other levels (including `rct-sim`). |
| `evidence_design` | `enum` | R | N | Structural design of the evidence. One of seven values such as `two_arm_comparison`, `dose_response_curve`, or `descriptive`. |
| `sources` | `object[]` | R | Y | Provenance trail. Each element is `{rank, type, name}`. `type` is an enum: `database`, `journal`, `simulation_model`, `seminar`, or `book`. `name` is the source name. Sorted before hashing. |
| `source_entry` | `str` | R | Y | Primary source entry identifier: database accession number, DOI, PMID, PMCID, or simulation-model version. |
| `source_time` | `str` | R | Y | Primary source time: last update time of a database entry or simulation model, or publication time of a journal article, seminar, or book. ISO-8601 preferred. |

## xy shape

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `xy.count` | `int` | R | N | Number of data points. `1` for descriptive, `2` for pairwise, `≥3` for sequential or dose-response. Determines expected array lengths. |

## x-axis

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `x.type` | `enum` | R | Y | Experimental variable type. `drug`, `gene`, `concentration`, `time`, or `combination`. |
| `x.unit` | `str` | C | N | Unit of `x.value`. Required when `x.type` is `concentration` or `time`. |
| `x.value` | `object[]` | R | Y | Ordered variable values. Length must equal `xy.count`. |

## y-axis

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `y.type` | `str` | R | Y | Human-readable endpoint name, e.g. "overall_survival" or "viability_72h". Free text. |
| `y.category` | `enum` | R | N | Controlled high-level endpoint category. Used for filtering, routing to Experts, and aggregate reporting. |
| `y.unit` | `str` | O | N | Unit of the outcome measurement, e.g. "percent", "months", "nM". |
| `y.to_basis` | `enum` | O | N | How the reported value relates to a baseline. `absolute`, `change`, `fold_change`, `log2_fold_change`, or `log10_fold_change`. |
| `y.value` | `number[]` | R | N | Ordered outcome values. Length must equal `xy.count`. |
| `y.dispersion` | `object[]` | O | N | Source-reported dispersion or interval as `[{type, value}]`. `type` is `SD`, `SEM`, `IQR`, `CI95`, or `range`. Length must equal `xy.count`. |
| `y.n_total` | `int[]` | O | N | Sample size per data point. Length must equal `xy.count`. |
| `y.events` | `int[]` | O | N | Event count for binary or time-to-event endpoints. Length must equal `xy.count`. |
| `y.p_value` | `float[]` | O | N | Source-reported p-values in `[0, 1]`. Length must equal `xy.count`. |
| `y.direction` | `enum` | C | N | Direction of effect: `beneficial`, `harmful`, or `neutral`. Required for comparative designs. |
| `y.effect` | `object` | O | N | Normalized effect estimate for cross-study synthesis. Schema: `{value, value_type, dispersion, dispersion_type}`. `value_type` is one of 16 effect measures. `dispersion_type` is one of `CI95`, `SD`, `SEM`, `SE`, `IQR`, or `range`. See `3.3_D-Base_enumerations.md` for the `value_type` selection guide. |
| `y.assay` | `str` | C | N | Assay or measurement platform, e.g. "IncuCyte", "ELISA". Required for non-clinical records. Excluded from identity by default. |

## Background

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `bg.disease_id` | `curie[]` | C | Y | Disease identifiers (MONDO/DOID/OMIM). Required for clinical levels; optional otherwise. Sorted before hashing. |
| `bg.drugs` | `object[]` | O | N | Drugs involved. Each element is `{entity_id, entity_label, dose?}`. |
| `bg.genes` | `object[]` | O | N | Genes or gene products involved. Each element is `{entity_id, entity_label, alteration?}`. |
| `bg.model` | `str` | O | N | Non-clinical modeling method or system description. Must not be present on clinical records. |
| `bg.dose_value` | `number` | O | Y | Dose or exposure amount. |
| `bg.dose_unit` | `str` | O | Y | Unit for `bg.dose_value`, e.g. "mg/kg", "µM". |
| `bg.duration_value` | `number` | O | N | Duration of exposure or observation. |
| `bg.duration_unit` | `str` | O | N | Unit for `bg.duration_value`, e.g. "hours", "days", "weeks". |
| `bg.phenotype` | `curie[]` | O | N | Phenotype terms as HPO CURIEs relevant to the evidence. |

## Sample

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `cell_line_id` | `curie` | C | Y | Cell line identifier (Cellosaurus prefix). Required for non-clinical cellular or higher-level records. Must not be present on clinical records. |
| `model_organism` | `curie` | O | Y | Model organism identifier (NCBITaxon prefix). |
| `strain` | `str` | O | Y | Specific strain or breed. |
| `sex` | `enum` | O | Y | `male`, `female`, or `mixed`. |
| `age` | `str` | O | N | Age descriptor, e.g. "8_weeks", "adults_18_65". Free text. |
| `tissue` | `curie` | O | N | Tissue identifier (UBERON prefix). |
| `cell_type` | `curie` | O | N | Cell type identifier (Cell Ontology / CL prefix). |
| `exvivo_platform` | `str` | C | N | Platform for exvivo evidence, e.g. "organoid". Required for `exvivo` and `exvivo-sim` levels. |

## Clinical

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `clinical_design.comparator_type` | `enum` | C | Y | Comparator arm: `placebo`, `active`, `standard_of_care`, or `no_treatment`. Required for comparative clinical designs. |
| `clinical_design.blinding` | `enum` | O | N | Blinding status: `open_label`, `single`, `double`, or `triple`. |
| `clinical_design.randomized` | `bool` | O | N | Whether participants were randomized. |
| `clinical_design.phase` | `enum` | O | Y | Trial phase: `phase_1`, `phase_2`, `phase_3`, or `phase_4`. |
| `clinical_design.n_arms` | `int` | O | N | Number of arms. |
| `clinical_design.population` | `enum` | O | Y | Target population: `adults`, `elderly_65_plus`, `pediatric`, `pregnant`, or `other`. |
| `clinical_design.study_id` | `curie` | O | Y | External study identifier, preferably `clinicaltrials:NCT...`. |

## Metadata

| Field | Type | Cardinality | in_id | Description |
|---|---|---|---|---|
| `related_evidence_id` | `str[]` | O | Y | Links to other `evidence_id`s from the same experiment, publication, or simulation run. |
| `is_primary_endpoint` | `bool` | O | N | Whether this was the primary endpoint in the source study. |
| `p_value_adjusted` | `bool` | O | N | Whether reported p-values were adjusted for multiple comparisons. |

## Sidecar fields

Sidecar fields are not part of the evidence record and never participate in the `evidence_id` hash. Each lives in its own append-only sidecar file keyed by `evidence_id`.

| Field | Type | Sidecar | Description |
|---|---|---|---|
| `status` | `enum` | `sidecars/status.jsonl` | Lifecycle state: `active`, `superseded`, `retracted`, `holdout-test`, or `holdout-valid`. Latest entry per `evidence_id` wins; a record with no entry is `active`. |
| `superseded_by` | `str` | `sidecars/status.jsonl` | `evidence_id` of the record that supersedes this one; carried on `superseded` entries. |
| LLM summary | `str` | `sidecars/llm_summary.jsonl` | Fallback free-text representation of the record; can be regenerated without changing evidence identity. |
| embedding | `number[]` | `sidecars/embeddings-{model_fp}.jsonl` | Dense vector for semantic search, generated by the active embedding model. |
