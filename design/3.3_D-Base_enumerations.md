# D-Base Enumeration Reference

> Controlled vocabularies used by the D-Base evidence schema and its sidecar fields. Values are grouped by the field they populate.

## 1. `biological_level`

Eleven levels that describe where the evidence was produced. The `-sim` suffix marks simulation-derived evidence.

| Value | Meaning |
|---|---|
| `molecular` | Biochemical or biophysical assays (binding, kinetics, expression) |
| `molecular-sim` | Simulation-derived molecular evidence |
| `cellular` | Cell-based assays (viability, proliferation, apoptosis) |
| `cellular-sim` | Simulation-derived cellular evidence |
| `exvivo` | Ex-vivo tissue or organoid assays |
| `exvivo-sim` | Simulation-derived ex-vivo evidence |
| `animal` | In-vivo animal studies |
| `animal-sim` | Simulation-derived animal evidence |
| `rct` | Randomized controlled clinical trial |
| `epi` | Epidemiological or real-world evidence |
| `rct-sim` | Simulation of a randomized controlled trial |

**Important:** `rct` and `epi` are clinical (`is_clinical = 1`). All others, including `rct-sim`, are non-clinical (`is_clinical = 0`). Clinical records must not carry non-clinical sample fields such as `cell_line_id` or `bg.model`.

## 2. `evidence_design`

Seven structural designs that determine how `x`, `y`, and statistics are interpreted.

| Value | Meaning |
|---|---|
| `two_arm_comparison` | Parallel-group comparison of two arms |
| `single_arm` | Single-arm study or cohort |
| `dose_escalation` | Dose-escalation design without full dose-response modeling |
| `dose_response_curve` | Multiple doses intended for dose-response modeling |
| `observational_association` | Observational association without randomization |
| `continuous_trajectory` | Longitudinal or time-series measurements |
| `descriptive` | Qualitative or single-point description (`xy.count = 1`) |

**Important:** The design drives conditional requirements. For example, `two_arm_comparison` requires `y.direction`, and clinical comparative designs require `clinical_design.comparator_type`.

## 3. `x.type`

The experimental variable being manipulated or observed.

| Value | Meaning |
|---|---|
| `drug` | Drug or drug combination as the variable |
| `gene` | Gene or genetic perturbation |
| `concentration` | Dose or concentration series |
| `time` | Time series |
| `combination` | Combinatorial variable (e.g. drug + gene) |

## 4. `y.category`

High-level endpoint category used for filtering, routing, and reporting. 23 values.

| Value | Meaning |
|---|---|
| `clinic_efficacy_*` | Clinical efficacy endpoints (domain-specific subcategories) |
| `clinic_toxicity_*` | Clinical toxicity/adverse-event endpoints (domain-specific subcategories) |
| `binding` | Binding assay |
| `pk_adme` | Pharmacokinetics / ADME |
| `prot_exp` | Protein expression |
| `rna_exp` | RNA expression |
| `viability` | Cell viability |
| `apoptosis` | Apoptosis |
| `proliferation` | Cell proliferation |
| `migration` | Cell migration |
| `invasion` | Cell invasion |
| `autophagy` | Autophagy |
| `differentiation` | Cell differentiation |
| `phosphorylation` | Phosphorylation / signaling |
| `localization` | Subcellular localization |
| `metabolism` | Metabolism |
| `oxidative_stress` | Oxidative stress |
| `behavioral` | Behavioral phenotype |
| `other` | None of the above |

**Important:** `y.category` is the controlled filter that routes evidence to Experts. `y.type` remains free text because endpoint names are too diverse to enumerate.

## 5. `y.direction`

Direction of effect for comparative evidence.

| Value | Meaning |
|---|---|
| `beneficial` | Favors the intervention |
| `harmful` | Favors the comparator or indicates toxicity |
| `neutral` | No meaningful difference |

## 6. `y.to_basis`

How the reported `y.value` relates to its baseline or reference.

| Value | Meaning |
|---|---|
| `absolute` | Raw measured value |
| `change` | Absolute change from baseline |
| `fold_change` | Ratio or fold-change relative to baseline |
| `log2_fold_change` | Log₂ fold-change relative to baseline |
| `log10_fold_change` | Log₁₀ fold-change relative to baseline |

**Important:** `fold_change` and the log variants are ratios. A value of `2.0` in `fold_change` means a doubling; `0.0` in `log2_fold_change` means no change.

## 7. `y.effect.value_type`

Normalized effect-measure type for cross-study synthesis, stored in `y.effect.value_type`. 16 values.

| Value | Meaning |
|---|---|
| `OR` | Odds ratio |
| `RR` | Relative risk |
| `HR` | Hazard ratio |
| `RD` | Risk difference |
| `MD` | Mean difference |
| `SMD` | Standardized mean difference |
| `IRR` | Incidence rate ratio |
| `NNT` | Number needed to treat |
| `NNH` | Number needed to harm |
| `cohens_d` | Cohen's d |
| `hedges_g` | Hedges' g |
| `glass_delta` | Glass's delta |
| `pearson_r` | Pearson correlation coefficient |
| `log_OR` | Natural log of odds ratio |
| `log_RR` | Natural log of relative risk |
| `log_HR` | Natural log of hazard ratio |

**Important:** When `value_type` is a log measure, `value` is expected to be on the log scale and `dispersion` should be the log-scale interval.

### `y.effect.dispersion_type`

| Value | Meaning |
|---|---|
| `CI95` | 95% confidence interval |
| `SD` | Standard deviation |
| `SEM` | Standard error of the mean |
| `SE` | Standard error of the estimate |
| `IQR` | Interquartile range |
| `range` | Min–max range |

### Choosing a `y.effect.value_type`

The choice depends on `biological_level`, `evidence_design`, `clinical_design.comparator_type`, and the nature of the endpoint.

| Evidence context | Recommended `y.effect.value_type` | Notes |
|---|---|---|
| Clinical (`rct`, `epi`), binary endpoint, two-arm comparison | `OR`, `RR`, or `RD` | `RR` is most interpretable for prospective studies; `OR` is common in case-control and logistic models. |
| Clinical (`rct`, `epi`), time-to-event endpoint | `HR` or `log_HR` | Requires `y.events` and `y.n_total` per arm. |
| Clinical (`rct`, `epi`), continuous endpoint, same scale | `MD` | Directly interpretable in original units. |
| Clinical (`rct`, `epi`), continuous endpoint, different scales | `SMD`, `cohens_d`, `hedges_g`, or `glass_delta` | Use when combining studies with different instruments or assays. |
| Clinical, single-arm or descriptive design | leave `y.effect` empty | Comparative effect measures require a comparator. Store the absolute outcome in `y.value`. |
| Epidemiological incidence or person-time data | `IRR` | For rates over person-time. |
| Observational correlation / association | `pearson_r` | When the evidence is an association without a controlled comparison. |
| Animal (`animal`, `animal-sim`), binary endpoint | `OR` or `RR` | e.g. tumor response or mortality. |
| Animal / cellular / exvivo / molecular, continuous endpoint | `MD` or `SMD` | `MD` when the readout scale is consistent; `SMD` when combining different assays or platforms. |
| Simulation (`*-sim`) | same as the emulated design | Match the effect type that the simulated real-world design would produce. |

**Comparator rule:** A comparative effect type (`OR`, `RR`, `HR`, `RD`, `MD`, `SMD`, `IRR`) is only appropriate when there is a comparator arm. For clinical records this means `clinical_design.comparator_type` is `placebo`, `active`, `standard_of_care`, or `no_treatment`. For non-clinical records it means the experiment includes a control condition encoded in `x.value`.

## 13. Sidecar field: `status`

`status` is a sidecar field, not part of the evidence record. It lives in `sidecars/status.jsonl`; the latest entry per `evidence_id` wins, and a record with no entry is `active`.

| Value | Meaning |
|---|---|
| `active` | Default; visible to Predict |
| `superseded` | Replaced by a newer record |
| `retracted` | Invalid; ignored by Predict |
| `holdout-test` | Reserved for the Benchmark test set |
| `holdout-valid` | Reserved for a validation set |

**Important:** `holdout-test` and `holdout-valid` are temporary states for holdout evaluation. Records in these states are restored to `active` after the evaluation completes so the store never permanently loses evidence.
